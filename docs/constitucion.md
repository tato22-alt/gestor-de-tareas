# Constitución

Ocho principios que el spec, el plan y el código no pueden contradecir. Si una función choca con uno, se cae la función.

1. **Cero curva de aprendizaje.** Su único canal es WhatsApp y habla como le habla a una persona: sin comandos, menús ni apps nuevas. Si hay que explicarle cómo usar algo, está mal diseñado.
2. **Nada se guarda sin que lo vea.** Cada captura vuelve como confirmación con fecha explícita: día y número, nunca solo "el jueves". Un error silencioso en una fecha o una promesa es peor que no tener la herramienta.
3. **Corregir es hablar.** Corregir, completar y deshacer se hace igual que cargar: con un audio o un texto, sin pasos especiales.
4. **Nunca habla en su nombre.** No les escribe a vecinos, clientes ni funcionarios; solo a él y a delegados que aceptaron. Un error saldría firmado por un concejal.
5. **Él tira, el sistema ordena.** Él manda la información desordenada; clasificar, vincular personas y detectar fechas es trabajo del sistema.
6. **Pocas funciones, muy confiables.** Una capacidad nueva entra solo si las anteriores se usan a diario y fallan poco. Cada prioridad se entrega y se prueba sola.
7. **Datos de terceros con cuidado.** Guarda datos personales de vecinos y contactos: lo mínimo, con acceso solo para él y quien autorice, exportable y borrable. Su número personal no se conecta a nada: el asistente tiene número propio y usa solo canales oficiales.
8. **Excel es una salida, no el depósito.** Las planillas se generan a pedido; dónde viven los datos se decide en el plan.
